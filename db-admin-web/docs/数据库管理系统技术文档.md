# 智映教匠AI平台 - 数据库管理系统技术文档

## 📖 系统概述

### 项目背景
智映教匠AI平台数据库管理系统是一个现代化的Web管理工具，旨在替代传统的命令行数据库操作方式，为管理员提供直观、高效的数据管理界面。

### 设计目标
- ✅ **简化操作**: 将复杂的SQL操作转化为可视化界面操作
- ✅ **提升效率**: 相比传统方式提升50%以上的管理效率
- ✅ **降低门槛**: 非技术人员也能轻松使用
- ✅ **保证安全**: 软删除机制，防止误删重要数据
- ✅ **响应设计**: 支持桌面端和移动端访问

## 🗄️ 数据库设计

### 核心表结构

#### 1. users (用户表)
```sql
CREATE TABLE users (
    id INT PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(50) NOT NULL UNIQUE,
    email VARCHAR(100) NOT NULL UNIQUE,
    password_hash VARCHAR(128) NOT NULL,
    avatar_url VARCHAR(200),
    is_active TINYINT(1) NOT NULL DEFAULT 1,
    last_login DATETIME,
    login_count INT NOT NULL DEFAULT 0,
    nickname VARCHAR(50),
    bio TEXT,
    phone VARCHAR(20),
    created_at DATETIME NOT NULL,
    updated_at DATETIME NOT NULL,
    is_deleted TINYINT(1) NOT NULL DEFAULT 0,
    deleted_at DATETIME
);
```

#### 2. questions (问题表)
```sql
CREATE TABLE questions (
    id INT PRIMARY KEY AUTO_INCREMENT,
    title VARCHAR(200) NOT NULL,
    content TEXT NOT NULL,
    user_id INT NOT NULL,
    status VARCHAR(20) NOT NULL DEFAULT 'pending',
    priority INT NOT NULL DEFAULT 0,
    view_count INT NOT NULL DEFAULT 0,
    answer_count INT NOT NULL DEFAULT 0,
    category VARCHAR(100),
    grade_level VARCHAR(50),
    subject VARCHAR(50),
    filter_tags JSON,
    created_at DATETIME NOT NULL,
    updated_at DATETIME NOT NULL,
    is_deleted TINYINT(1) NOT NULL DEFAULT 0,
    deleted_at DATETIME,
    FOREIGN KEY (user_id) REFERENCES users(id)
);
```

#### 3. videos (视频表)
```sql
CREATE TABLE videos (
    id INT PRIMARY KEY AUTO_INCREMENT,
    title VARCHAR(200) NOT NULL,
    description TEXT,
    file_path VARCHAR(500) NOT NULL,
    file_size INT NOT NULL,
    duration FLOAT,
    format VARCHAR(20) NOT NULL,
    video_metadata JSON,
    thumbnail_path VARCHAR(500),
    user_id INT NOT NULL,
    upload_ip VARCHAR(50),
    upload_time DATETIME NOT NULL,
    status VARCHAR(20) NOT NULL DEFAULT 'processing',
    error_message TEXT,
    view_count INT NOT NULL DEFAULT 0,
    like_count INT NOT NULL DEFAULT 0,
    comment_count INT NOT NULL DEFAULT 0,
    created_at DATETIME NOT NULL,
    updated_at DATETIME NOT NULL,
    is_deleted TINYINT(1) NOT NULL DEFAULT 0,
    deleted_at DATETIME,
    FOREIGN KEY (user_id) REFERENCES users(id)
);
```

#### 4. feedbacks (反馈表)
```sql
CREATE TABLE feedbacks (
    id INT PRIMARY KEY AUTO_INCREMENT,
    title VARCHAR(200) NOT NULL,
    content TEXT NOT NULL,
    user_id INT NOT NULL,
    type ENUM('BUG', 'FEATURE', 'COMPLAINT', 'PRAISE', 'OTHER') NOT NULL,
    status ENUM('PENDING', 'PROCESSING', 'RESOLVED', 'CLOSED') NOT NULL,
    priority ENUM('LOW', 'MEDIUM', 'HIGH', 'URGENT') NOT NULL,
    handler_id INT,
    handle_note TEXT,
    handle_time DATETIME,
    created_at DATETIME NOT NULL,
    updated_at DATETIME NOT NULL,
    is_deleted TINYINT(1) NOT NULL DEFAULT 0,
    deleted_at DATETIME,
    FOREIGN KEY (user_id) REFERENCES users(id),
    FOREIGN KEY (handler_id) REFERENCES users(id)
);
```

#### 5. answers (回答表)
```sql
CREATE TABLE answers (
    id INT PRIMARY KEY AUTO_INCREMENT,
    content TEXT NOT NULL,
    question_id INT NOT NULL,
    user_id INT NOT NULL,
    is_accepted TINYINT(1) NOT NULL DEFAULT 0,
    is_ai_generated TINYINT(1) NOT NULL DEFAULT 1,
    like_count INT NOT NULL DEFAULT 0,
    dislike_count INT NOT NULL DEFAULT 0,
    created_at DATETIME NOT NULL,
    updated_at DATETIME NOT NULL,
    is_deleted TINYINT(1) NOT NULL DEFAULT 0,
    deleted_at DATETIME,
    FOREIGN KEY (question_id) REFERENCES questions(id),
    FOREIGN KEY (user_id) REFERENCES users(id)
);
```

### 索引设计

```sql
-- 用户表索引
CREATE INDEX idx_users_is_deleted_is_active ON users(is_deleted, is_active);
CREATE INDEX idx_users_created_at ON users(created_at);

-- 问题表索引  
CREATE INDEX idx_questions_user_id ON questions(user_id);
CREATE INDEX idx_questions_filter ON questions(is_deleted, status, grade_level, subject);
CREATE INDEX idx_questions_created_at ON questions(created_at);

-- 视频表索引
CREATE INDEX idx_videos_user_id ON videos(user_id);
CREATE INDEX idx_videos_status ON videos(status, is_deleted);
CREATE INDEX idx_videos_upload_time ON videos(upload_time, status);

-- 反馈表索引
CREATE INDEX idx_feedbacks_user_id ON feedbacks(user_id);
CREATE INDEX idx_feedbacks_handler_id ON feedbacks(handler_id);
CREATE INDEX idx_feedbacks_status ON feedbacks(status, priority, is_deleted);

-- 回答表索引
CREATE INDEX idx_answers_question_id ON answers(question_id);
CREATE INDEX idx_answers_user_id ON answers(user_id);
CREATE INDEX idx_answers_filter ON answers(question_id, is_deleted, is_accepted);
```

## 🔌 API接口文档

### 基础配置
- **基础URL**: `http://localhost:8080/api`
- **认证方式**: 暂无（开发阶段）
- **数据格式**: JSON
- **字符编码**: UTF-8

### 统一响应格式
```json
{
    "success": true|false,
    "message": "操作结果描述",
    "data": {} | []
}
```

### 接口列表

#### 1. 仪表板统计
**GET** `/dashboard/stats`

**响应示例**:
```json
{
    "success": true,
    "data": {
        "users": {"total": 8, "active": 6},
        "questions": {"total": 77, "pending": 12, "answered": 65},
        "videos": {"total": 30, "total_size": 1288490188, "ready": 28},
        "feedbacks": {"total": 2, "pending": 1, "high_priority": 0}
    }
}
```

#### 2. 用户管理
**GET** `/users`

**查询参数**:
- `page`: 页码 (默认: 1)
- `per_page`: 每页数量 (默认: 20)
- `search`: 搜索关键词

**DELETE** `/users/{user_id}`

#### 3. 问题管理
**GET** `/questions`

**查询参数**:
- `page`: 页码
- `per_page`: 每页数量
- `search`: 搜索关键词
- `status`: 问题状态
- `grade_level`: 年级层次
- `subject`: 学科分类

**DELETE** `/questions/{question_id}`

#### 4. 视频管理
**GET** `/videos`

**查询参数**:
- `page`: 页码
- `per_page`: 每页数量
- `search`: 搜索关键词
- `status`: 视频状态

**GET** `/videos/{video_id}/stream`

**DELETE** `/videos/{video_id}`

#### 5. 反馈管理
**GET** `/feedbacks`

**查询参数**:
- `page`: 页码
- `per_page`: 每页数量
- `search`: 搜索关键词
- `status`: 处理状态
- `priority`: 优先级

**DELETE** `/feedbacks/{feedback_id}`

## 🔧 部署指南

### 开发环境

#### 环境要求
- Python 3.8+
- Node.js 16+
- MySQL 8.0+
- npm 或 yarn

#### 一键启动
```bash
cd db-admin-web
./start.sh
```

#### 手动启动
```bash
# 后端
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python run.py

# 前端
cd frontend
npm install
npm run dev
```

### 生产环境

#### Docker部署
```dockerfile
# 前端Dockerfile
FROM node:16-alpine
WORKDIR /app
COPY package.json .
RUN npm install
COPY . .
RUN npm run build
EXPOSE 5173
CMD ["npm", "run", "preview"]

# 后端Dockerfile
FROM python:3.8-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY . .
EXPOSE 8080
CMD ["gunicorn", "run:app", "--host", "0.0.0.0", "--port", "8080"]
```

#### Nginx配置
```nginx
server {
    listen 80;
    server_name your-domain.com;
    
    # 前端静态文件
    location / {
        proxy_pass http://localhost:5173;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
    
    # 后端API
    location /api {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

## 🔒 安全考虑

### 数据安全
- **软删除机制**: 重要数据标记删除而非物理删除
- **数据备份**: 每日自动备份数据库
- **访问控制**: 基于角色的权限管理 (计划中)
- **数据加密**: 敏感数据加密存储 (计划中)

### 网络安全
- **CORS配置**: 限制跨域请求来源
- **SQL注入防护**: 使用参数化查询
- **XSS防护**: 输入验证和输出编码
- **HTTPS**: 生产环境强制HTTPS

### 操作安全
- **操作日志**: 记录所有管理操作
- **备份确认**: 删除操作前确认备份
- **权限最小化**: 最小权限原则
- **定期审计**: 定期检查权限和数据

## 🐛 问题排查

### 常见问题

#### 1. 数据库连接失败
**症状**: 后端启动时显示数据库连接错误

**解决方案**:
```bash
# 检查MySQL服务状态
sudo systemctl status mysql

# 检查数据库是否存在
mysql -u root -p -e "SHOW DATABASES LIKE 'ai_platform';"

# 验证连接配置
python3 -c "import pymysql; pymysql.connect(host='localhost', user='root', password='123456', database='ai_platform')"
```

#### 2. 前端页面空白
**症状**: 浏览器显示空白页面

**解决方案**:
```bash

cd frontend
npm run build
```

#### 3. API接口404

**解决方案**:
```bash
# 检查后端服务状态
curl http://localhost:8080/api/dashboard/stats
```
